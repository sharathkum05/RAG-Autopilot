# Reference: the source document

`Introduction_to_Python_Programming-WEB.pdf` is the public textbook behind the ViDoRe V3 Python subset this demo indexes.
It is here for context only; the pipeline does not read it.

- **Book:** *Introduction to Python Programming*, OpenStax (2024)
- **Source:** https://openstax.org/details/books/introduction-python-programming
- **License:** Textbook content produced by OpenStax is licensed under a
  [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
  Download for free at openstax.org.

**Page numbers differ.** This PDF is OpenStax's current web edition (397 pages). ViDoRe V3 ships its own render of the
book as 415 page images, and every page number in the app, the citations and the evals refers to those 415 pages
(`scripts/download_vidore_v3.py` fetches them).
